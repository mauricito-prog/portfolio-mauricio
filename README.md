# Portefólio Pessoal - Mauricio Ito

Olá! Bem-vindo ao repositório do meu portefólio pessoal. Este projeto foi desenvolvido para apresentar minhas competências, certificados e projetos como programador iniciante, com foco em desenvolvimento web e programação orientada a objetos.

## 🚀 Tecnologias Utilizadas

Este portefólio é construído com tecnologias web fundamentais, demonstrando proficiência em:

-   **HTML5**: Estruturação semântica do conteúdo.
-   **CSS3**: Estilização moderna, incluindo layouts responsivos com Flexbox, gradientes e animações.
-   **JavaScript (ES6+)**: Interatividade, manipulação do DOM, efeitos visuais (como o efeito de digitação) e integração com serviços externos (EmailJS).
-   **Font Awesome**: Biblioteca de ícones para enriquecer a interface.
-   **EmailJS**: Serviço para envio de e-mails diretamente do formulário de contacto, sem a necessidade de um backend.

## ✨ Funcionalidades

-   **Design Responsivo**: O layout se adapta perfeitamente a diferentes tamanhos de tela, desde desktops a dispositivos móveis.
-   **Navegação Suave**: Scroll suave entre as secções da página para uma experiência de utilizador fluida.
-   **Efeito de Digitação no Hero**: Um efeito visual dinâmico no título principal da página, destacando meu nome.
-   **Animação de Barras de Competências**: Barras de progresso animadas que aparecem ao rolar a página até a secção de "Competências".
-   **Carrossel de Certificados**: Um carrossel interativo para exibir diplomas e certificados, com navegação por botões e rolagem.
-   **Overlay "Ver" em Certificados**: Em dispositivos touch, um toque no certificado revela um overlay "Ver", e um segundo toque abre o PDF. Em desktop, o efeito é ativado por hover.
-   **Formulário de Contacto Funcional**: Um formulário que permite aos visitantes entrar em contacto diretamente, utilizando EmailJS para o envio de e-mails.
-   **Foto de Perfil Interativa na Navbar**: Uma pequena foto de perfil na barra de navegação que se amplia ao passar o mouse.
